- Canvas API for the neural-network animation
- Google Fonts
- Zero frameworks, zero build tools — just open `index.html`

## 🚀 Run Locally

Just open `index.html` in any browser. Or serve it locally:

```bash
npx serve .
# or
python3 -m http.server 8000
```

## 📦 Deploy

This repo is deployed with **GitHub Pages**:

1. Upload `index.html` to the repo root
2. Go to **Settings → Pages**
3. Source: **Deploy from a branch** → `main` → `/ (root)` → Save
4. Live at `https://<username>.github.io/<repo>/`
